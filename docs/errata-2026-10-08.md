# 2026년 3권 정오표 반영 및 영향 분석

10월 8일 공지 PDF(문서 작성 기준일 2026-10-06)를 원문 3권 PDF 및 기존 문제 데이터에 대조했다. 37문제의 47개 필드를 수정했으며, 문제 수 750개와 기존 문제 ID·순서·인쇄 페이지를 유지한다.

- 원문 PDF SHA-256: `28b7560d4be4f1a5ce9ddcc6a8d94ddc534e3fbe663047911d6b81d8de3c4341`
- 정오표 PDF SHA-256: `47490ec58833a9ff7e350c1aa6c9c929a01f5daa7e6b74ed3ef5e33cbf93099d`
- 수정 이력: [data/errata-2026-10-08.json](../data/errata-2026-10-08.json). 각 항목에 문제 ID, 정오표 PDF 페이지, 데이터 경로, 수정 전·후 값을 기록한다.
- 원본 PDF 해시는 원본 증빙으로 유지하고 데이터 개정판은 별도 `revision`으로 식별한다.

## 보기·해설을 구분해 반영한 항목

**기업여신 39번:** 정오표에 따라 정답만 ④에서 ①로 변경한다. 보기·문제 본문·원문 해설은 유지한다. 별도 추가 확인 경고는 표시하지 않는다.

**수신제도 55번:** 정오표 PDF 1~2페이지에서 기존 해설 전체(③·④ 포함)가 취소선으로 삭제됐다. 수정 후에 제시된 새 ① 해설만 반영하고, 삭제된 해설은 복원하지 않는다. 정답은 기존 ②를 유지한다. 수정 이력과 독립적인 검사로 해설 전체를 확인해, 데이터와 수정 이력을 함께 바꾸더라도 삭제된 문구가 다시 들어오는 것을 감지한다.

**신용카드 16번:** 정오표는 ③ 보기에서 ‘전액 연회비 또는’를 삭제한다. ‘틀린 것’을 묻는 문제이므로 보기의 1,000포인트리와 원문 해설의 100포인트리를 모두 1,000으로 바꾸면 오답 선택지가 정답 문장으로 바뀔 수 있다. 보기의 1,000과 기존 해설의 100은 유지하고, 해설에도 삭제된 연회비 혜택을 남기지 않는다. 해설의 100포인트리 기준 변경은 이번 정오표에 명시되지 않았으므로 임의로 변경하지 않는다.

**집합투자 43번:** 수정 전 문구가 원문 보기와 해설 중 해설에 해당한다. 보기의 ‘초과금액에 한하여’를 유지하고 해설에 사적연금 전액과 분리과세 선택 가능 내용을 반영한다. 보기까지 정답 문장으로 덮어써서 틀린 보기를 없애지 않는다.

**수신제도 38번:** 정오표에 ② 보기가 문맥으로 함께 인용돼 있지만 수정 후 별도 보기 교체는 제시하지 않는다. ②의 잘못된 설명을 바로잡는 해설과 ④의 ‘명의의 → 명의인’만 수정해 단일 정답 ④를 유지한다.

**가계여신 92번:** 정오표의 표 및 해설을 함께 교체한다. 정답은 변경 공지가 없으므로 ④를 유지한다. 표의 ①에 ‘등록’, ③에 ‘미등록’이라고 적힌 것은 오답 보기이므로 해설 문구에 맞춰 정답 문장으로 고치지 않는다. 표 이미지는 정오표 PDF 6페이지에서 직접 추출한 수정 후 표로 교체해 텍스트와 그림이 일치하도록 한다.

**가계여신 43번:** 표 텍스트의 ‘견간 → 연간’을 수정한다. 기존 표 원본 이미지는 증빙으로 유지하며 화면에서 ‘정오표 적용 전’이라고 표시한다.

## 검증

- 수정 이력을 역순으로 되돌린 문제은행이 수정 전 데이터와 동일한지 전체 데이터 해시로 검사한다. 관련 없는 713문제 및 원본 위치 정보를 보존한다.
- 37문제·47개 수정 필드·정답 변경 4개·표와 이미지 참조를 검사한다.
- 정오표 PDF 11페이지에서 독립적으로 확인한 과목·문제번호·출처 페이지와 수정 대상 37문제가 일치한다. 수정 대상 전체의 복습 재등록과 수정하지 않은 문제 및 미풀이 북마크의 기록 보존을 검사한다.
- 실제 이전 배포판 `4695dfe`의 엔진과 문제 데이터로 750문제·1,500회 풀이 기록을 생성해 이전했다. 모든 과거 점수·풀이 횟수·북마크를 유지하고 수정 대상 37문제만 복습을 초기화하며 나머지 713문제는 진도가 동일했다. 구판 저장소 키에서 IndexedDB로 이전, 반복 로드, 미응답을 포함한 완료 모의고사의 점수 보존도 확인했다.
- 수정 필드를 중복 집계하지 않는다. 수신제도 105번의 법명 및 띄어쓰기 수정은 같은 보기 필드 한 건으로 기록한다.
- 옛 정답에 따른 정답·오답 점수 및 재시도, 새 정답 채점, 진도·북마크 보존, 복습 재등록, 이전 답안 변경 방지, 모의고사 만료, 백업 가져오기, 반복 이전, 답안 공개 전 정오표 숨김을 검사한다.
- `npm run test:pages`, `npx tsc --noEmit -p .`, `npm run build:pages`, `npm run test:ui`로 엔진·타입·배포 빌드·화면 흐름을 검증한다.

## 사용자가 확인할 부분

정오표 반영 내용에 대해 추가로 확정해야 할 항목은 없다. 실제 사용자 기기의 저장 기록은 테스트 환경에서 접근할 수 없으므로 다음을 확인하는 것이 좋다.

1. 배포 전에 기존 주소의 ‘내 기록’에서 백업을 내보내고, 진행 중인 모의고사는 마친다. 새 버전에서 이어 제출하면 새 정답 기준으로 채점된다.
2. 배포 후 학습 탭을 모두 새로고침하고, 기존 풀이 수·북마크·완료 시험 점수가 유지되는지 확인한다. 이미 푼 수정 문제가 ‘오늘 복습’에 다시 포함되는 것은 의도한 동작이다.
3. 기업여신 39번은 ①로 채점되는지, 가계여신 92번은 새 표 및 표 원본이 표시되는지 확인한다. 자동 화면 검사는 통과했으며, 이 확인은 실제 사용 기기에서 배포 결과를 확인하기 위한 것이다.

PDF 전체를 공개 저장소에 추가하지 않는다. 원본 증빙 좌표는 기존 교재 기준이며, 정오표 출처는 별도 메타데이터로 표시한다. PR을 병합하면 기존 GitHub Actions가 사이트를 배포한다.
