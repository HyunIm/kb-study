# KB Study

로그인 없이 사용하는 2026 은행실무 문제은행 학습 사이트입니다.

- 750문제, 원문 정답·해설·표·이미지, 인쇄 페이지 우선 표시
- 문제 풀이, 오답·헷갈림·북마크 복습, 50문항·60분 모의고사
- 학습 기록은 브라우저 IndexedDB에 저장됩니다. 서버로 전송하지 않습니다.
- 다른 기기로 이동하거나 브라우저 데이터를 지우기 전에는 기록 백업을 이용해주세요.
- 백업 가져오기는 현재 기록을 교체합니다. 호환되지 않는 파일은 거절합니다.
- 같은 브라우저 프로필을 사용하는 사람은 기록을 공유합니다.
- 시험 시간은 기기의 시계를 기준으로 계산합니다. 공식 평가용이 아닙니다.
- 공개 정적 사이트이므로 문제와 정답 데이터 자체를 숨길 수는 없습니다.
- 직원공모·변형문제는 아직 포함되지 않았습니다.

## 개발과 검증

Node.js 24 이상에서 `npm ci`, `npm run test:pages`, `npm run build:pages`를 실행합니다.
로컬 실행은 `npm run dev`입니다.

## GitHub Pages

저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다.
main 브랜치에 커밋하면 테스트 및 빌드 후 dist-pages 디렉터리를 배포합니다.
URL: https://hyunim.github.io/kb-study/

기존 서버 서비스의 계정·학습 기록은 이 정적 버전에 자동으로 이전되지 않습니다.
